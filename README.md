# Python Crash Kurs

Herzlich Willkommen zu diesem Kurs. Dieser Kurs deckt die Grundlagen von Python ab und bietet erste Einblicke in die Programmierung.

> [!note] Module
1. Einrichtung & erste Schritte
2. Datenbanken, Variablen & Ausgaben
3. Kontrollstrukturen
4. Funktionen
5. Listen, Tupel & Schleifen
6. Dictionaries
7. Objektorientierte Programmierung (OOP)

> [!note] Ablauf
- Module der Reihe nach bearbeiten
- Jedes Modul baut auf dem vorherigen auf
- Vor dem nächsten Modul sollte das aktuelle abgeschlossen sein

> [!note] Voraussetzungen
Keine. Modul 1 deckt alles ab, was für den Kurs benötigt wird.
