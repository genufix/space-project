## Lizenzierung der Assets

Das Spiel verwendet ausschließlich Assets, die sowohl für die private als auch für die kommerzielle Nutzung freigegeben sind.

Die hier verwendeten **Game Assets** stammen von der Plattform [itch.io](https://itch.io/) sowie [kenney.nl](https://kenney.nl/).

### Sprites:
- [Space Shooter - Redux](https://kenney.nl/assets/space-shooter-redux) von **Kenney**

### Musik:
- [Synthwave Music Pack](https://alkakrab.itch.io/free-shooter-synthwave-music-pack) von **alkakrab** (Spiel, `music/synthwave/`)
- [Music Loops](https://kenney.nl/assets/music-jingles) von **Kenney**, CC0 (Menü, `music/menu/`)

### Sounds:
- [Halftone Sound Effects](https://void1gaming.itch.io/halftone-sound-effects-pack-lite) von **VOiD1 Gaming**
- [Sci-Fi Alarm SFX](https://sound-works-12.itch.io/sci-fi-alarm-sfx-free) von **Sound Works 12**
- [Interface Sounds](https://kenney.nl/assets/interface-sounds) von **Kenney**, CC0 (Menü-Bestätigung, `sounds/ui/`)

### Fonts:
- [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P) von **CodeMan38**, SIL Open Font License
  (siehe `fonts/OFL.txt`)
