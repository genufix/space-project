# Dein Arbeitsordner

Hier entsteht dein Spiel! Lege in [Aufgabe 1](../exercises/exercise-01/README.md) deine `main.py`
an und erweitere sie danach Aufgabe für Aufgabe. Ab [Aufgabe 5](../exercises/exercise-05/README.md)
kommt eine `settings.py` dazu. Mehr braucht es nicht: Am Ende besteht dieser Ordner nur aus diesen
zwei Dateien (diese README kannst du ignorieren oder löschen).

> [!NOTE] Info:
>
> Starten kannst du dein Spiel jederzeit vom Projekt-Root aus mit:
> ```sh
> uv run game/main.py
> ```
